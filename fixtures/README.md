# Development fixtures

All catalogue rows in this directory are fictional and exist to exercise the importer and reader. E1234 occurs in two layers at the same point in Pittsburgh. The Eggs example also exercises a blank clutch count, a matching audit row, a supplied article and an unresolved locality. The Fluids image illustrates the species using the credited Catesby engraving. The Skins file includes a duplicate identifier for review.

Use the development commands in the repository README. The development build is labeled in the header and writes to `.local/demo-site/`.
