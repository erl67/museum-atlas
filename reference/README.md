# Eggs location references

`egg-places.json` is a compact, import-only extract of the offline geographic reference in the [Eggs location notebook, revision d466eb9](https://github.com/erl67/museum-collection-analysis/blob/d466eb9d5a0b78febc52ec06a08c206a69dd8c09/Egg_collection_location_heatmap.ipynb). It contains the notebook's normalized geographic keys, latitude, longitude and method. The Atlas omits the notebook's heat-map geometry and egg weights.

The 630 locality entries use [GeoNames](https://www.geonames.org/) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). County references use the [US Census Bureau 2025 Gazetteer](https://www.census.gov/geographies/reference-files/time-series/geo/gazetteer-files.html), and state/province references use [Natural Earth](https://www.naturalearthdata.com/). Keys retain the notebook's country and administrative context. This file belongs alongside the importer and is excluded from the upload.
